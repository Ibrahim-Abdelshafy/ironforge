# IronForge — Fitness Studio Landing Page

A fully responsive fitness studio landing page built with pure HTML and CSS.

## Features
- Responsive navbar with mobile stacking
- Full-height hero section with CTA buttons
- Classes section with hover-animated cards
- Pricing tiers with highlighted recommended plan
- Footer with navigation links

## Tech Stack
- HTML5
- CSS3 (Flexbox, CSS Variables, Media Queries)

- **Navbar** — Logo, navigation links, CTA button
- **Hero** — Headline, subtitle, dual CTA buttons
- **Classes** — Strength Training, HIIT Cardio, Yoga & Flexibility
- **Pricing** — Starter, Pro, Elite plans with feature lists
